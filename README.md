Empirical-comps pre-token launch radar and chain-aware farming desk for DeFi protocols. Calibrates category MCap/TVL multiples directly from live-token comparables in the sealed snapshot via Empirical Bayes shrinkage, combines TVL, 7-day momentum, pre-token maturity, and multi-chain footprint, and generates chain-aware farming plans with explicit capital, gas, and time budgets.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /input/snapshot.json
```
